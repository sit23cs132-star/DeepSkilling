# Week 1 – Python Fundamentals, Data Structures & Best Practices

This directory contains foundational exercises, notes, and implementations for Week 1 of the FSE Deep Skilling program.

## Directory Contents

### 1. Data Structures & Algorithms (`Data_structures/`)
- `arrays(Searching).py` → Python script demonstrating array operations and searching algorithms.
- `sorting_algorithm` → Python script implementing Bubble Sort and Quick Sort algorithms.

### 2. Database Integration (`Database_integration/`)
- `hands_on_1_sql.db` → SQLite database for Hands-on Exercise 1.
- `hands_on_2_sql.db` → SQLite database for Hands-on Exercise 2.

### 3. Design Patterns & Principles (`Design_patterns/`)
- `singleton_example.py` → Python implementation of the Singleton design pattern.
- `solid_principle_notes.md` → Comprehensive study notes detailing SOLID design principles.

### 4. Unit Testing (`Uniit_testing/`)
- `test_math_function.py` → Unit tests for mathematical functions using Python's `unittest` module.
- `test_string_utils.py` → Unit tests for string utility functions.

---

## How to Run

### Data Structures & Design Patterns
Run individual scripts directly with python:
```bash
python Data_structures/arrays(Searching).py
python Data_structures/sorting_algorithm
python Design_patterns/singleton_example.py
```

### Unit Tests
To execute the test cases:
```bash
python -m unittest Uniit_testing/test_math_function.py
python -m unittest Uniit_testing/test_string_utils.py
```
