# QA Concepts Notes

## Defect Lifecycle
1. New → defect reported
2. Assigned → given to developer
3. Fixed → developer resolves
4. Retest → tester verifies
5. Closed → defect resolved
6. Reopen → if issue persists

## Test Strategy
- Unit Testing → developers test functions
- Integration Testing → modules tested together
- System Testing → end-to-end validation
- Regression Testing → ensure old features still work

## Automation Strategy
- Identify repetitive test cases
- Automate login, navigation, form submissions
- Use Selenium + PyTest for browser automation
