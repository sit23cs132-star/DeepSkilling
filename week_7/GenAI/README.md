# Generative AI Demos

This module contains sample scripts demonstrating key Generative AI applications:

- `text_generation.py`: Text generation using Hugging Face Transformers pipeline with GPT-2.
- `image_generation.py`: Image generation using Diffusers library with Stable Diffusion v1.5.
- `chatbot_demo.py`: Rule-based baseline chatbot demonstration.

## Setup & Dependencies
```bash
pip install transformers diffusers torch accelerate
```

## Running the Demos
```bash
python text_generation.py
python image_generation.py
python chatbot_demo.py
```
