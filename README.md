# Python FSE Deep Skilling

Welcome to the **Python Full Stack Engineering (FSE) Deep Skilling** program repository. This repository hosts all hands-on exercises, backend frameworks, frontend architectures, QA automation code, and study guides completed throughout the 5-week training schedule.

## 📚 Modules Overview

### 🗓️ Week 1: Python Fundamentals & Software Design
*   📖 **Module Documentation:** [Week_1.md](week_1/Week_1.md)
*   **Data Structures & Algorithms:** Practical implementations of Search algorithms, Bubble Sort, and Quick Sort.
*   **Database Integration:** Hand-on SQLite setups and data operations.
*   **Design Patterns:** Concrete implementation of the Singleton pattern and detailed notes on **SOLID Principles**.
*   **Unit Testing:** Quality validation suites using Python’s native `unittest` package.

### 🗓️ Week 2: Backend Development & Advanced Testing
*   📖 **Module Documentation:** [Week_2.md](week_2/Week_2.md)
*   **Django Backend:** A database-driven REST API using Django REST Framework (DRF) mapping `Course` and `Department` entities.
*   **Flask Backend:** A lightweight Flask application integrated with SQLite using Flask-SQLAlchemy.
*   **FastAPI Backend:** A modern, high-performance async API with Pydantic validations and automated testing suites.
*   **Advanced Testing:** Leveraging PyTest fixtures and database transactional mocks.

### 🗓️ Week 3: Frontend Development Basics
*   📖 **Module Documentation:** [Week_3.md](week_3/Week_3.md)
*   **Structure & Semantics:** HTML5 form layout for course administration.
*   **Aesthetics:** Modern CSS styling incorporating hover effects and responsive layouts.
*   **Dynamic Logic:** Client-side JavaScript DOM management, form validation, and asynchronous JSON data retrieval.

### 🗓️ Week 4: Frontend Frameworks
*   📖 **Module Documentation:** [Week_4.md](week_4/Week_4.md)
*   **React:** SPA architecture demonstration using state Hooks (`useState`) and props communication.
*   **Angular:** Framework layout demonstrating component architecture, modules, and directives (`*ngFor`).
*   **Vue:** Lightweight frontend module showing reactive data-binding and Single File Component (SFC) layout.

### 🗓️ Week 5: QA Concepts & Selenium Automation
*   📖 **Module Documentation:** [Week_5.md](week_5/Week_5.md)
*   **QA Theory:** Defect lifecycles, test strategy documentations, and test case matrices.
*   **Automation:** Selenium WebDriver configurations integrated into PyTest suites.
*   **Design Pattern:** Implementation of the **Page Object Model (POM)** pattern to build robust, maintainable UI tests.

### 🗓️ Week 6: Selenium Advanced & DevOps Basics
*   📖 **Module Documentation:** [Week_6.md](week_6/Week_6.md)
*   **Selenium Advanced:** Synchronization with explicit waits, page screenshot generation, file upload handling, and extended Page Object Model patterns.
*   **DevOps Basics:** Docker containerization, `docker-compose` orchestration, Flask app integration, GitHub Actions CI workflows, and Jenkins declarative pipelines.
