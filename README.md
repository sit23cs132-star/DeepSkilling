# Python FSE Deep Skilling

Welcome to the **Python Full Stack Engineering (FSE) Deep Skilling** program repository. This repository hosts all hands-on exercises, backend frameworks, frontend architectures, QA automation code, and study guides completed throughout the 5-week training schedule.

---

50: ## 📚 Modules Overview
51: 
52: ### 🗓️ Week 1: Python Fundamentals & Software Design
53: *   📖 **Module Documentation:** [Week_1.md](week_1/Week_1.md)
54: *   **Data Structures & Algorithms:** Practical implementations of Search algorithms, Bubble Sort, and Quick Sort.
55: *   **Database Integration:** Hand-on SQLite setups and data operations.
56: *   **Design Patterns:** Concrete implementation of the Singleton pattern and detailed notes on **SOLID Principles**.
57: *   **Unit Testing:** Quality validation suites using Python’s native `unittest` package.
58: 
59: ### 🗓️ Week 2: Backend Development & Advanced Testing
60: *   📖 **Module Documentation:** [Week_2.md](week_2/Week_2.md)
61: *   **Django Backend:** A database-driven REST API using Django REST Framework (DRF) mapping `Course` and `Department` entities.
62: *   **Flask Backend:** A lightweight Flask application integrated with SQLite using Flask-SQLAlchemy.
63: *   **FastAPI Backend:** A modern, high-performance async API with Pydantic validations and automated testing suites.
64: *   **Advanced Testing:** Leveraging PyTest fixtures and database transactional mocks.
65: 
66: ### 🗓️ Week 3: Frontend Development Basics
67: *   📖 **Module Documentation:** [Week_3.md](week_3/Week_3.md)
68: *   **Structure & Semantics:** HTML5 form layout for course administration.
69: *   **Aesthetics:** Modern CSS styling incorporating hover effects and responsive layouts.
70: *   **Dynamic Logic:** Client-side JavaScript DOM management, form validation, and asynchronous JSON data retrieval.
71: 
72: ### 🗓️ Week 4: Frontend Frameworks
73: *   📖 **Module Documentation:** [Week_4.md](week_4/Week_4.md)
74: *   **React:** SPA architecture demonstration using state Hooks (`useState`) and props communication.
75: *   **Angular:** Framework layout demonstrating component architecture, modules, and directives (`*ngFor`).
76: *   **Vue:** Lightweight frontend module showing reactive data-binding and Single File Component (SFC) layout.
77: 
78: ### 🗓️ Week 5: QA Concepts & Selenium Automation
79: *   📖 **Module Documentation:** [Week_5.md](week_5/Week_5.md)
80: *   **QA Theory:** Defect lifecycles, test strategy documentations, and test case matrices.
81: *   **Automation:** Selenium WebDriver configurations integrated into PyTest suites.
82: *   **Design Pattern:** Implementation of the **Page Object Model (POM)** pattern to build robust, maintainable UI tests.
83: 
84: ### 🗓️ Week 6: Selenium Advanced & DevOps Basics
85: *   📖 **Module Documentation:** [Week_6.md](week_6/Week_6.md)
86: *   **Selenium Advanced:** Synchronization with explicit waits, page screenshot generation, file upload handling, and extended Page Object Model patterns.
87: *   **DevOps Basics:** Docker containerization, `docker-compose` orchestration, Flask app integration, GitHub Actions CI workflows, and Jenkins declarative pipelines.
88: 
89: ### 🗓️ Week 7: Generative AI & Cloud
90: *   📖 **Module Documentation:** [README.md](Week7_GenAI_Cloud/README.md)
91: *   **GenAI:** Hugging Face text generation, Diffusers image generation pipeline, and interactive chatbot demonstration.
92: *   **Cloud:** Multi-cloud operations across AWS (EC2/S3/Lambda), Azure (Blob Storage/Function App), GCP (Cloud Storage/Cloud Functions), and Terraform IaC provisioning.
