# Week 4 – Frontend Frameworks

This folder contains starter projects for React, Angular, and Vue.

## Contents
- **React_App/** → React components with state and props
- **Angular_App/** → Angular modules, components, and services
- **Vue_App/** → Vue templates, reactive data, and props

## How to Run
- React: `npm start` inside React_App
- Angular: `ng serve` inside Angular_App
- Vue: `npm run serve` inside Vue_App
