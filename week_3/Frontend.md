# Week 3 – Frontend Development Basics

This folder contains solutions for Week 3 of the Python FSE Deep Skilling program.

## Contents
- `index.html` → Basic HTML structure with a form and list
- `styles.css` → CSS styling using selectors, flexbox, and hover effects
- `script.js` → JavaScript for DOM manipulation, event handling, and async fetch

## How to Run
1. Open `index.html` in a browser.
2. Add a course using the form.
3. Courses will appear in the list.
4. The script also fetches sample data from a mock API (`jsonplaceholder.typicode.com`).
